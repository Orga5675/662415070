# NightFuel Traceability DApp

A blockchain-based product traceability DApp built with Solidity, Ethereum Sepolia, MetaMask, HTML, CSS, JavaScript, and ethers.js.

## Smart Contract

Network: Ethereum Sepolia

Contract Address:
`0x8525A3DCa9334fEB6A7A454044d9F1B573517476`

## Features

- Connect MetaMask
- Display connected wallet
- Create product batches on-chain
- Verify batch information from the blockchain
- Display transaction hash after confirmation

## Frontend

Open `frontend/index.html` with VS Code Live Server, then connect MetaMask on the Sepolia network.
